네이버 블로그 꾸미기 키트

blog.naver.com/own_system에 홈페이지와 같은 스킨, 카톡 문의 창구, 주문 신청 버튼을 넣는 방법입니다. 네이버 블로그는 직접 만든 입력 폼을 넣을 수 없어서, 버튼을 누르면 주문 신청서 페이지로 이동하도록 연결합니다.

STEP 1타이틀 이미지 (PC)

title.png 내려받기 · 966 × 320 px

  1. 블로그 관리 → 꾸미기 설정 → 세부 디자인 설정으로 들어갑니다.
  2. 왼쪽 타이틀에서 디자인을 직접등록으로 바꾸고 title.png를 올립니다.
  3. 블로그 제목 글자 표시는 끄고(이미지에 이미 들어 있습니다), 영역 높이를 320으로 맞춘 뒤 적용합니다.
  4. 배경색은 #F7F1E7로 지정하면 홈페이지와 같은 바탕이 됩니다.

STEP 2사이드바 위젯: 주문 · 카톡 · 전화

  1. 관리 → 꾸미기 설정 → 레이아웃·위젯 설정으로 들어갑니다.
  2. 아래쪽 위젯 직접등록을 누르고, 위젯 이름과 아래 코드를 붙여 넣습니다. 세 개를 각각 등록합니다.
  3. 등록한 위젯을 사이드바 맨 위로 끌어 올린 뒤 적용합니다.

STEP 3글 하단 배너 (모바일에서도 보임)

post-banner.png 내려받기

  1. 글을 쓸 때 맨 아래에 post-banner.png를 사진으로 넣습니다.
  2. 사진을 선택하고 링크 버튼을 눌러 주소를 넣습니다: https://link.myowndesign.co.kr/furniture/#order
  3. 사진 아래에 글로 한 번 더 적어 두면 좋습니다: “주문 신청서 ▶ 링크 / 카톡 상담 ▶ pf.kakao.com/_JxiWGG / 전화 031-572-2114”

STEP 4공지글과 블로그 소개

  1. “주문·상담 안내” 글을 하나 써서 STEP 3 배너와 링크를 넣고 공지로 등록합니다. 블로그 첫 화면 위쪽에 고정됩니다.
  2. 관리 → 기본 설정 → 블로그 정보의 소개글에 한 줄을 넣습니다.
