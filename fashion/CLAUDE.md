# 패션 계정 자동 게시 작업 지침

사용자가 "fashion 폴더 올려줘" 같은 말을 하면 아래 순서로 진행한다.
계정 정보는 `profile.json`, 말투는 `voice.md`를 따른다.

## 순서
1. `fashion/inbox/` 아래의 새 폴더를 찾는다. 폴더 하나가 게시물 하나다.
   - 폴더 이름: `날짜_룩이름` (예: `1005_grey-cargo`)
   - 안에 사진들, 그리고 선택으로 `items.txt` (한 줄에 `종류 / 브랜드 / 제품명 / 사이즈`)
2. 사진을 직접 보고 어울리는 **게시 순서**(대표 컷 → 측면 → 디테일 → 거울샷 ...)를 정한다.
3. `voice.md` 규칙대로 **캡션 1개와 첫 댓글용 해시태그**를 쓴다. 안 보이는 사실은 지어내지 않는다.
4. **사이즈 카드**를 만든다. `fit/index.html`을 브라우저로 열어 `profile.json` 값과 `items.txt` 내용을 넣고 PNG로 저장한다. `items.txt`가 없으면 사진으로 확실히 알 수 있는 종류만 넣고 사이즈는 사용자에게 묻는다.
5. 사진 + 사이즈 카드(마지막 장) + 캡션을 **Meta Business Suite(business.facebook.com)에서 인스타그램 게시물로 예약**한다.
   - 이 계정은 Buffer가 아니라 Meta Business Suite를 쓴다. 인테리어 계정의 Buffer 예약은 건드리지 않는다.
   - 순서: 게시물 만들기 → 인스타그램 계정(`mool_jumeok`) 선택 → 사진 업로드(순서대로, 마지막이 사이즈 카드) → 캡션 입력 → 일정 설정에서 날짜와 시간 지정 → 예약.
   - 화면 이름이 다르면 같은 뜻의 메뉴를 찾아 진행하고, 달랐던 부분을 보고에 적어 이 지침을 고칠 수 있게 한다.
   - 시간은 `profile.json`의 요일과 시간. 이미 예약된 칸은 캘린더에서 확인하고 건너뛴다.
   - 해시태그는 본문에 넣지 않는다. 첫 댓글용으로 보고에 적어 둔다.
   - 다른 인스타 계정(인테리어 등)이 같은 Meta 로그인에 연결돼 있으면, **반드시 `mool_jumeok` 계정이 선택됐는지 확인**한 뒤 예약한다.
6. 끝나면 `fashion/posted/날짜_룩이름.md`에 캡션, 해시태그, 예약 시간, 사진 목록을 기록하고, 처리한 폴더를 `fashion/posted/`로 옮긴다. `profile.json`의 `next_look_number`를 1 올린다.
7. 사용자에게 한 번에 보고한다: 예약된 시간, 캡션, 그리고 직접 해야 할 일(음악 붙이기 등).

## 하지 말 것
- 예약이 아니라 즉시 게시하지 않는다. (사용자가 "지금 바로"라고 한 경우만)
- 로그인 정보나 토큰을 레포나 대화에 적지 않는다. 로그인이 풀려 있으면 사용자에게 로그인해 달라고 요청한다.
- 얼굴이나 개인정보가 남이 찍힌 사진이 섞여 있으면 올리지 말고 사용자에게 먼저 묻는다.
